# SafeGraph AI

The complete SafeGraph AI application lives in [`ai/`](ai/). It contains the Streamlit UI, prediction services, training pipeline, datasets, trained model artifacts, and dependency manifest.

## Start the application

```powershell
cd ai
streamlit run app.py
```

For the full architecture, setup instructions, data contract, and prediction commands, see [`ai/README.md`](ai/README.md).
